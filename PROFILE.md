## APIs

- **GenderAPI.io** — REST + JSON API that infers gender from first/full names, email addresses, and social usernames, with bulk/multi-country requests, phone validation, and credit/quota endpoints. Supports Bearer token and API-key query authentication. (`https://api.genderapi.io`)

> GenderAPI.io is the only publicly consumable developer interface Ozan Soft exposes; it has a verified live OpenAPI 3.1 contract (JSON + YAML), Swagger UI, Postman collection, official SDKs in six languages (JavaScript, PHP, Python, Java, R, Ruby), and credit-based pricing with a free tier. No agent-native surfaces of its own: no official MCP server, no llms.txt, no published agent skills. Third-party 'Gender API' MCP wrappers exist (Composio, viasocket, community lists) but are not published by Ozan Soft and several appear to target the unrelated gender-api.com — not attributable here. Ozan Soft's other products (Revito.net, ASINsell.com, BahceTakip.com) have no public API.
