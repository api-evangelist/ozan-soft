# GenderAPI

> GenderAPI provides name-, email-, and username-based gender inference, country-aware results, bulk workflows, and developer documentation.

Use the API documentation for current request formats and error behavior.

Gender results are probabilistic inferences from name-related evidence, not verified statements of a person's identity. Preserve unknown and low-confidence outcomes.
